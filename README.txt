
SauceDemo Selenium Framework Starter

Technologies:
- Java
- Selenium
- Maven
- TestNG
- Page Object Model (POM)

How to Run in Eclipse:

1. Open Eclipse
2. File -> Import -> Existing Maven Projects
3. Select this folder
4. Right click project -> Maven -> Update Project
5. Run testng.xml

Included:
- BaseClass
- Login Page
- Inventory Page
- Login Test
- Add To Cart Test
